连接你的手柄

  1. 通过 USB、蓝牙或无线接收器连接手柄。
  2. 按一下手柄按键，让浏览器识别设备。
  3. 选好节奏和强度，点击「开始」。

建议使用桌面版 Chrome / Edge。手柄能被识别，不一定能震动；支持情况取决于浏览器、系统和连接方式。未提供震动功能时，可以试试 USB 连接或 PulsePad 桌面版。

切换标签页、最小化、锁屏或手柄断开会停止。恢复后请手动开始。Esc 可停止；已映射手柄也可按右侧面键停止。

两个滑块控制低频与高频通道，实际马达位置由设备决定。网页支持 16 种震动节奏，音乐功能请使用桌面版。
